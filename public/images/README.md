# Managing image files #

This folder holds image assets for the website. Add images here and reference them from your site HTML/CSS or static site generator. Suggested structure that meets criteria for many AI html creators:

- public/images/icons/  (for small icons)
- public/images/photos/ (for large photos)
- public/images/logos/  (for logos)

Add optimized images (webp, avif when supported) and commit them to this folder.
